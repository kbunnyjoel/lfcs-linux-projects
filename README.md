# lfcs-linux-projects

Practical Linux projects from beginner to advanced for LFCS preparation.

## Projects

- [Project 1: Nginx Setup Automation](project1-nginx-setup/README.md)  
  Automated deployment and configuration of Nginx for development and production environments. Includes systemd service management, SSL setup, and basic hardening.

- [Project 2: System Monitoring Dashboard](project2-system-monitor/README.md)  
  A comprehensive dashboard for monitoring system metrics and health in real time. Provides outputs in text, JSON, and Prometheus formats; runs via Docker on macOS/Linux; includes a Prometheus HTTP endpoint at :9100 for scraping.

- [Project 3: User & Access Management Toolkit](project3-user-management/README.md)  
  Toolkit to automate Linux user, group, and access management. Covers sudoers automation, password policies, and audit logging.
