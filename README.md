# lfcs-linux-projects

Practical Linux projects from beginner to advanced for LFCS preparation.

## Projects

- [Project 1: Nginx Setup Automation](project1-nginx-setup/README.md)  
  Automated deployment and configuration of Nginx for development and production environments.

- [Project 2: System Monitoring Dashboard](project2-system-monitor/README.md)  
  A comprehensive dashboard for monitoring system metrics and health in real time.

- [Project 3: User & Access Management Toolkit](project3-user-access-management/README.md)  
  A containerized Bash toolkit for safe, idempotent Linux user and group management with automated tests and linting.

- [Project 4: Backup Orchestrator](project4-backup-orchestrator/README.md)  
  A script-driven orchestrator for automated backups, including scheduling, verification, and environment-specific configuration.

- [Project 5: Service Watchdog](project5-service-watchdog/README.md)  
  A fault-tolerant service watchdog built with shell scripts, Bats tests, Docker, and email notifications. Supports retries, exponential backoff, and environment configuration for development and production.

- [Project 6: Storage & Filesystems Watchdog](project6-storage-filesystems-watchdog/README.md)  
  A multi-sprint filesystem health watchdog with Bash scripts, Bats tests, logging, and reporting, aligned with LFCS storage objectives.
